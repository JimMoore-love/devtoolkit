DevToolkit 开发工具助手

端口 / 服务发现 · 进程管理 · 项目托管 · 命令历史 —— 集成 11 项网络工具箱（Ping · 路由追踪 · 端口扫描 · 测速 · WOL · 子网计算 · 弱电计算 · 运维百宝箱），全部本地运行，零云端依赖。

🪟

Windows

Windows 10/11 · x64 · 免安装绿色版 · 9.4 MB
⬇ 立即下载 .exe
下载后双击即可运行（首次若提示 SmartScreen，点「仍要运行」）。数据保存在 %APPDATA%\cn.devtoolkit.app。
🍎

macOS（Apple Silicon / Intel）

macOS 11+ · 源码 + 一键构建脚本 · 122 KB
⬇ 下载源码包
解压后执行 bash build-macos.sh，自动装 Rust（国内镜像）→ 编译 → 生成 DevToolkit.app 并启动。全程约 5-10 分钟，仅需运行一次。
核心能力
为命令行开发者打造的本地管控台
🔌
端口 / 服务发现

netstat 实时解析，TCP/UDP 筛选、PID 定位、进程名解析、一键结束

🚀
项目托管

命令行项目一键启动/停止，实时日志流（stdout+stderr 着色）、退出码、Uptime

📡
Ping 测试

延迟波动图 + 最小/最大/平均/丢包摘要，历史对比

🛤
路由追踪

tracert / traceroute 逐跳展示，定位网络断点

🔍
端口扫描

原生 TCP 并发扫描（64 线程），支持范围表达式 8000-8005，常见服务名标注

🏠
主机发现

ARP 表实时读取 + MAC 厂商识别（华为/海康/大华/小米…）+ 厂商分布图

🚀
下载测速

Cloudflare / 中科大 / 阿里云三源切换，Mbps 实时统计

💡
WOL 网络唤醒

魔术包 UDP 广播，远程唤醒局域网设备

🧮
子网 / MAC 计算

IPv4 子网划分、网络/广播地址、可用范围，OUI 厂商查询

⚡
弱电计算器

供电功率 / 机柜散热 / 布线预算 / PoE 供电四大计算器

📖
运维百宝箱

华为 / 思科 / H3C / 锐捷 / Windows / Linux 六大命令速查库

📊
仪表盘

CPU / 内存实时折线、监听端口数、运行任务数、操作时间线

🚀 快速开始

Windows

1
点击上方下载 DevToolkit-win-x64.exe
2
双击运行（SmartScreen 提示时选「仍要运行」）
3
左侧导航进入「网络工具箱」即可使用全部网络工具

macOS

1
下载源码包并解压：tar xzf devtoolkit-src.tar.gz
2
进入目录执行 bash build-macos.sh（自动装 Rust 国内镜像 + 编译）
3
构建完成后自动生成并打开 DevToolkit.app；可 mv DevToolkit.app /Applications/ 永久安装
